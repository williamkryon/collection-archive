# Offline cutout model

`isnet-general-use-q8.onnx` is a quantized ONNX export of the IS-Net general-use
foreground segmentation model from Xuebin Qin et al., "Highly Accurate
Dichotomous Image Segmentation" (ECCV 2022).

- Upstream project: https://github.com/xuebinqin/DIS
- ONNX distribution: https://huggingface.co/SacredNoir/isnet-general-use-onnx
- License: Apache-2.0 (see `ISNET-LICENSE.md`)
- SHA-256: `feed6f32a5e707ca7e939576b2d891b23fb9eb4114749657a5efc64e8651e43a`

The model runs locally through ONNX Runtime. Collection images are not uploaded.
